# QA Bootcamp Learning Materials
This repository contains materials, assignments, and practice exercises completed during the QA Bootcamp. 
Throughout the program, I learned fundamental software testing concepts, 
including test case design, bug reporting, test execution reporting, API testing, 
Gherkin syntax, and basic SQL for data validation.

# Test Case Creation
Learned how to design and create structured test cases by defining test scenarios, preconditions, test steps, test data, expected results, and actual results to ensure application functionality meets requirements.
